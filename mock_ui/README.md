# Adhithiya HRMS mock flow

Open `index.html` in any modern browser. The prototype uses only HTML, CSS, and vanilla JavaScript; no build step or dependency installation is needed.

Use the role selector in the left sidebar to preview the Super User, HR Sub-User, and Employee navigation boundaries. The screens model the SRS workflows only: access control, organization settings, employee records, leave, attendance, productivity, goals, appraisals, payroll, payslips, notifications, reports, and the read-only audit log.

This is a front-end mock. Buttons, exports, uploads, and workflow state changes are illustrative and do not store data or call an API.
